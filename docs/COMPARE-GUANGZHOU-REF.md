# 产品对标：方块鹏城 vs 方块羊城（参考站 522e7c37.pinme.dev）

> 分析日期：2026-10-19
> 参考站：`https://522e7c37.pinme.dev`（PinMe/IPFS 托管，「方块羊城 · Block Guangzhou」）
> 本地项目：`block-shenzhen`（「方块鹏城 · Block Shenzhen」，全栈）

## 一、架构形态差异

| 维度 | 参考站「方块羊城」 | 本地「方块鹏城」 |
|------|-------------------|------------------|
| 部署 | 纯前端 SPA（Vite + PinMe/IPFS） | 全栈（Vue3 + Java17 + MySQL8） |
| 存档 | localStorage（纯本地） | JWT 云存档（30s 定时 + 退出上传） |
| 账号 | 无账号系统 | 游客 JWT + 后端登录 |
| 后端能力 | 无 | 埋点 / 作品广场 / 灰度 / 版本管理 / 商店 |
| 渲染 | 程序化 + 内容驱动 | 程序化 + GLTF 低模管线（P0/P1/P2） |

## 二、参考站独有、本地缺失的核心玩法

### 1. 美食系统（本地缺，但任务已引用）
- 9 种广府美食：叉烧/肠粉/云吞面/烧鹅/双皮奶/艇仔粥/牛杂/凉茶/咖啡
- 通过**店铺 NPC** 购买（茶楼/银记肠粉/云吞面世家/深井烧鹅/南信双皮奶/艇仔粥摊/牛杂档/沙面咖啡馆）
- 美食图鉴收集，任务 `食在广州`（尝 6 种）→ 金筷子
- 本地任务 `d_food2`/`q_food` 已引用 `daily:food`/foodCount，但引擎无美食玩法来源

### 2. 广府文化图鉴（本地缺，但任务已引用）
- 9 项：粤剧/舞狮/广府文化/骑楼/陶塑灰塑/五羊传说/木棉/龙舟/早茶文化
- 图鉴解锁收集，任务 `岭南文化达人`（解锁 6 项）
- 本地 `d_culture`/`q_culture` 已引用 `daily:culture`/cultureCount，引擎无来源

### 3. 纪念品/收藏系统（本地缺）
- 20+ 种：小蛮腰模型/醒狮挂件/陈家祠木雕/五羊公仔/广彩瓷杯/羊城通卡/折扇/明信片/旅行纪念章/木棉书签/粤剧脸谱/夜游船票/索道票根/区徽章（越秀/荔湾/天河/海珠/白云/番禺/南沙）
- 通过任务奖励、店铺购买、体验玩法获取

### 4. 天气系统（本地缺）
- 雨/雪（粒子效果），`setWeather` 切换
- 天气触发 NPC 对白（"落雨喇快啲避雨"、"打风喇"）

### 5. 日夜循环（本地缺）
- `timeSpeed`/`setTime`，夜晚调整色调曝光（`toneMappingExposure=1.05+night*0.45`）
- 夜景任务（`d_night` 夜晚拍照）、珠江夜游夜景

### 6. 观景台登顶（本地缺）
- 广州塔电梯登顶俯瞰（deck 玩法），登顶任务奖励徽章

### 7. 自拍玩法（本地缺，但任务已引用）
- `selfie` 自拍，每日任务 `d_selfie`（本地已引用 `daily:selfie`，无实现）

### 8. 动态随机 NPC 系统（本地是静态 6 个）
- 职业加权生成：上班族/学生/老人/游客/小孩/街坊
- 随机姓氏（陈李黄梁何张林罗郭冯麦邓谭吴杨）× 职业称呼（先生/同学/伯/游客/仔/师傅）
- 职业专属对白 + 天气触发对白 + 夜晚对白
- 店铺 NPC 带商品售卖交互

### 9. 特殊交通（本地仅地铁）
- 观光巴士（busStop 站牌）、珠江夜游（cruise）、白云索道缆车（cable）
- 本地 `ride` 条件已支持 bus/metro/boat/cable，但场景交通主要地铁

## 三、本地独有、参考站没有的能力（本地优势）

1. **建造系统** + 作品广场（G 键发布/浏览/点赞/导入他人作品）
2. **商店 + 地标投资被动经济**（¥800×等级，¥300/h）
3. **飞升阶段系统**（newcomer→explorer→builder，能力解锁）
4. **全栈云存档**（JWT，跨设备回档）
5. **灰度发布 / 版本管理 / 回滚 / diff**
6. **埋点分析**（session/visit/photo/quest/economy/build/ui）
7. **移动端触控适配**（摇杆/虚拟键/响应式 HUD）
8. **GLTF 真实模型渲染管线**（P0 阴影 / P1 角色动画 / P2 贴图）
9. 内容驱动场景（scene JSON 可后台发布）

## 四、待办优先级建议（补齐参考站核心玩法）

### P0（补齐被引用但无实现的任务条件，否则每日任务永远无法完成）
- 美食系统：店铺 NPC + 美食购买 + `daily:food` 计数
- 文化图鉴：`daily:culture` 计数
- 自拍：`daily:selfie` 计数
- 夜晚拍照：`daily:nightPhoto` 计数 + 日夜循环

### P1（体验级玩法）
- 日夜循环（timeSpeed/setTime + 曝光/光照调整）
- 天气系统（雨雪粒子 + NPC 天气对白）
- 动态随机 NPC（职业/姓氏/称呼/对白）
- 纪念品收藏系统

### P2（丰富度）
- 观景台登顶（deck）
- 观光巴士 / 珠江夜游 / 索道 等特殊交通
- 店铺 NPC 售卖互动

## 五、关键实现路径提示

- 每日任务计数：`Gameplay.evalCond` 的 `daily:xxx` 分支目前仅支持 `daily:photo`，其余全部走 `(inventory>=999?n:0)` 死路。需要为 food/culture/selfie/nightPhoto/bus/metro/talk/districts/walk 增加真实计数来源（事件驱动）。
- 天气/日夜：参考站通过 `time` 字段驱动光照与曝光，本地 `atmosphere.ts` 的 `buildLighting` 可扩展为按时间参数化。
- NPC 随机生成：本地 `NpcSystem` 是摆位式，可扩展为运行时生成 + 职业对白池。
