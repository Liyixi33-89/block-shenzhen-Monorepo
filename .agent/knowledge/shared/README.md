# 共享层知识（Shared）

> 前端、后端、后台**三者共用**的领域知识：内容数据模型、领域术语、跨端常量、架构级决策。不专属任何单一端。

| 文件 | 内容 |
|---|---|
| `data-model.md` | 内容 JSON（场景/地标/任务/NPC/交通/建造/经济）全字段语义 |
| `schema.md` | `packages/schema` 包结构地图 + 校验规则（zod）+ 存档 schema + 消费入口 |
| `glossary.md` | 领域术语 + 跨端常量 + 区主题色 |
| `decisions.md` | 跨端架构决策 ADR |
| `engineering.md` | 工程验证脚本（`scripts/`：verify 三级管线 / check-docs 防腐 / check-layering 分层守护） |
| `product.md` | 产品/架构长文档索引（`docs/`：前端架构方案 / admin 可配置化 PRD / 对比广州对标） |

改内容 JSON / schema / 领域概念 / 工程脚本 / 产品文档时查阅本目录。
