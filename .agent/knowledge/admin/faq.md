# 后台 FAQ（Admin）

> 内容后台（apps/admin）高频疑问速答。内容字段语义见 `../shared/data-model.md`。

## 登录与权限

**admin 登录怎么验证？**
登录走 `/api/auth/login`，后端下发 `bsz_token` HttpOnly Cookie；前端不持有 token，用 `/api/auth/me` 校验会话。本地账号 `admin / aszx123@`。

**提示未登录/被踢？**
cookie 会话由后端管理。登出只是清本地用户信息（HttpOnly cookie 前端不可读，由后端过期）。若会话过期，路由守卫自动回 `/login`。

**为什么用户列表搜不到刚注册的账号？**
`UsersPanel` 用 `/api/admin/users?keyword=&limit=50`，先确认关键词/分页；该端点受 `AdminGuard` 保护，需当前账号为 admin 角色。

## 编辑与保存

**切页签会不会丢修改？**
不会——所有页签编辑**同一份** `scene` 响应式对象，切页签不销毁。但切路由会弹确认（有 `dirty` 时），登出会提示丢失。建议先「保存草稿」。

**改完怎么生效到游戏？**
两步：①「保存草稿」（`PUT`）→ ②「发布新版本」（`POST`，自动 bump patch）。发布后 web 前端用 `?playerId=` 拉取（灰度/最新）。草稿≠已发布。

**发布失败提示校验问题？**
看顶部 `issues` 列表（`path: message`），是后端 `JacksonSchemaValidator` 报的。修复后重新保存/发布。发布还要求版本 semver 严格递增（`bumpPatch` 已自动处理）。

**字段改了没看到数量/颜色变化？**
admin 不跑游戏引擎。数值、地图点位、主题色等改动在**发布后由 web 引擎消费**；admin 侧只反映 JSON 数据本身。

## 地图拾点

**MapPicker 没有显示某个点？**
MapPicker 自动取景覆盖「地标/出生点/传送点/区中心」；若坐标超出自动取景范围（或数据 <2 点），用默认兜底视野。点击地图即可拾取当前坐标。

**改区中心/出生点/传送点坐标？**
在对应页签选中条目后，用 `MapPicker` 点击地图（金色十字准星 = 当前拾取点），或直接在地图上点击更新经纬度。

## 版本/灰度

**灰度滑杆怎么生效？**
滑杆设置 `percent` →「应用灰度」。玩家 ID 稳定哈希分桶，桶值 < percent 得最新版。灰度不等于全量，需逐步放大并观察埋点漏斗。

**如何紧急全量回滚？**
「版本」页签「回滚/锁定」选历史版本 → 回滚锁定。所有玩家立即切到该版本。

## JSON 高级编辑

**JSON 页签改完没反应？**
`JsonEditor` 是**独立文本区**，需点「应用 JSON」写回 `scene`，且 `id` 必须为 `shenzhen-main`；写回后再「保存草稿」+「发布」。切走页签再回来会重新生成文本（丢失未应用修改）。

*排查「改内容不生效」按：内容是否发布 → schema 校验 → 引擎是否读取 → 构建产物是否更新 四步。*
